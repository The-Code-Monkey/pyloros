# Resolve one advisory-free version per package

Every Package Identity appears at most once in a tree, at the highest version that satisfies every declared range and peer constraint and has no open security advisory. A deterministic backtracking solver produces the Clean Resolution Set; when no clean version exists, the user makes a Fallback Selection rather than the tool silently choosing. Nested trees were rejected because duplicate versions multiply the attack surface and make the installed tree unreviewable, warn-and-continue was rejected because it hides known vulnerabilities, and automatic hard failure was rejected because it leaves no path forward for affected packages. The consequence is that resolution depends on live advisory data, and the Advisory Snapshot in the lockfile is what makes a past resolution reproducible.
