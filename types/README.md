# Vendored Node type declarations

Source: `@types/node@26.6.6` and `undici-types@8.9.0` from the npm registry.
Licenses: see the `LICENSE` files in each directory.

These declarations are vendored so Pyloros can self-host its development toolchain without depending on a package that declares no `engines.node`. They are only used for type checking; they are not a runtime dependency.

Do not edit these files. To update, pack newer versions, replace both directories, and update this note.
